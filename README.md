Free entry, five minutes of work: your bot paper-trades pump.fun on a 6-hour replay, highest net PnL takes the pot. Any strategy counts - even buy-and-hold.

This entry is a **late-curve momentum rider**: it probes cheap round trips just above the
guardrail bar (>= 0.01 SOL on >= 20 coins) and puts rare, small entries only into mature curves
whose tape shows broad, accelerating buy pressure with no single dominant wallet, then rides to
curve completion. Design and parameter sweep in [STRATEGY.md](STRATEGY.md).

## Run it

```sh
node main.ts
```
